# Free Flow Music

Free Flow Music is a no-ads web music player with:
- local MP3 upload and playback (stored in browser IndexedDB)
- URL-based track playback
- queue, repeat, shuffle
- JSON import + Spotify/YouTube metadata import
- per-song download

## Run locally
Open `index.html` in a modern browser.
